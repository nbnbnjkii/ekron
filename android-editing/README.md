# Где редактировать HUD, управление и лобби

Здесь разложены **копии исходников** для удобного изучения. Они не участвуют
в Android-сборке. Это не самостоятельный проект: общие зависимости, модели,
текстуры, видео и библиотеки сюда не скопированы.

```text
android-editing/
├── Управление/
│   ├── Общее/    — HUD, кнопки, джойстики, редактор управления, JNI и Renderer
│   ├── Игрок/    — движение, бег, прыжок, приседание, джетпак, руки и инструменты
│   ├── Дрон/     — FPV-стики, полёт, камеры и взрыв
│   └── Машина/   — подвеска, проходимость, динамика, посадка и выход
└── Лобби/        — комната GLES, мониторы, интерфейс и видео
```

В каждой подпапке есть README с описанием файлов и ссылками на рабочие оригиналы.

## Важные общие файлы

Кнопки игрока, дрона и машины не полностью разделены по разным исходникам:

- `Управление/Общее/MainActivity.kt` — размещение кнопок HUD, переключение режимов,
  бег, действия джетпака, газ и руление. Здесь же открывается и закрывается лобби.
- `Управление/Общее/TouchControls.kt` — рисунок кнопок, джойстика и обработка касаний.
- `Управление/Общее/ControlEditorView.kt` — настройка положения и размера управления.
- `Управление/Общее/Renderer.cpp` — JNI, разгон/скорость/руление машины,
  обновление физики и переходы камер, в том числе показ взрыва FPV.
- `Управление/Машина/Interaction.h` — высота и положение камеры водителя.

Общие файлы скопированы один раз, а не размножены для каждого режима.

## Как вносить рабочие изменения

1. Найди нужный файл здесь и прочитай пояснения в README его раздела.
2. Меняй **оригинал** в `sys/android/app/src/main/`, а не только эту копию.
3. Повтори изменение в соответствующем файле `game-source/sys/android/`.
4. Проверь тесты и Android-сборку.
5. Обнови эти копии командой из корня репозитория:

   ```bash
   python3 tools/export_editing_sources.py
   ```

**Внимание:** команда перезаписывает перечисленные копии и README разделов.
Не оставляй здесь единственный экземпляр своих правок.

`sources.json` содержит исходный путь и SHA-256 каждой копии для проверки,
что она соответствует рабочему файлу. Сам экспортёр:
[`tools/export_editing_sources.py`](../tools/export_editing_sources.py).

Рабочие исходники не перенесены и их пути для Gradle/CMake не изменены.
