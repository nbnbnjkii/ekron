# Рисунки и надписи лобби

`export.mjs` исполняет оригинальные Canvas-функции `src/game/textures.ts` из
пользовательского `military-lobby-ui-design.zip` и упаковывает 16 рисунков
в `sys/android/app/src/main/assets/lobby/artwork.png`. Это офлайн-инструмент:
Node/Canvas/TypeScript не нужны приложению и не включаются в APK.

```sh
npm ci --prefix tools/lobby-art
npm run export --prefix tools/lobby-art
```

Скопируйте обновлённые PNG/JSON в аналогичную папку game-source после экспорта.
Рисунки: знамя ЭКРОН, тактическая карта и её табличка, шкаф «ОПАСНО 380 В»,
четыре названия мониторов, шесть маркировок ящиков, бочка «ГСМ», полоса опасности.
Плитки в атласе квадратные; правильные пропорции восстанавливаются на геометрии.
Используются оригинальные шрифты Russo One и JetBrains Mono (SIL OFL, лицензии
в fonts/). Геометрию и назначение плиток задаёт LobbyDecor.h, JSON хранит номера.

PNG декодируется нативно в отдельной фоновой задаче. Видео не извлекается
в картинки: MediaPlayer непрерывно проигрывает assets/intro.mp4 внутри экрана
№03. Заголовок/нижняя строка монитора остаются видимыми; до подготовки декодера
и при ошибке вместо чёрного прямоугольника видна заставка монитора.

Экран №02 с настройками не изменён.
