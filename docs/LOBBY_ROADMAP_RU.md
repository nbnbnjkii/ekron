# Запрос: военное 3D-лобби, управление, машина и джетпак

## Выполненная часть этой ветки
- Полный наклон стика даёт ходьбу 2.7 м/с. Бег 5.8 м/с включается отдельной удерживаемой кнопкой над левым стиком.
- Приседание и ползание не ускоряются кнопкой бега, диагональ нормализована.
- Состояние бега сбрасывается при паузе, потере фокуса, уходе в фон и FPV. Сама кнопка скрыта при сидении.
- Покачивание рук при ходьбе слабее, чем при беге; прежний running в ToolArtView обозначает активность отрисовки, а не скорость игрока.
- Native регрессия проверяет скорости, диагональ, приседание и ползание. Длительность прежней проверки преодоления подоконника увеличена под новую скорость ходьбы; высоты/коллизии не ослаблены.

## Ещё НЕ выполнено (не объявлять готовым)
1. Военное просторное квадратное лобби с четырьмя стенными интерактивными экранами. Взаимодействие по месту касания, без модалок и приближения камеры.
2. Экран 1: приветствие, новая игра / продолжить; выбор творческого / выживания; играть / назад. Реального игрового режима выживания сейчас нет — нельзя просто подписать существующий sandbox «выживание».
3. Экран 2: информация; при возврате из игры — настройки согласно последнему уточнению пользователя. Экран 3: intro-видео в мире, пауза по тапу. Экран 4: предложить полезное назначение (например, обучение).
4. В лобби скрыть всё кроме ходьбы/обзора/прыжка/приседания; запретить строительство на нативной стороне, а не только скрыть кнопки.
5. Пауза в игре возвращает в лобби без потери сессии. Продолжить восстанавливает прежнее состояние. Кнопка сохранения показывает «Игра сохранена» только после успешной записи.
6. Настройки: звук; редактирование HUD перетаскиванием, выбор размера при нажатии; отдельные профили игрок / машины / дрон; сохранение и сброс раскладки.
7. Машина: выяснить фактическое управление — в текущем Renderer сидящий игрок следует за driverSeat, но нет обработки газа/руля. Нужен полноценный проверяемый driving controller, а не только увеличение константы скорости. Проверить точные коллайдеры против ранней остановки у стены, подвеску/шаг на небольших камнях и неровностях; не отключать столкновения. Целевая скорость выше скорости бега.
8. Джетпак: отдельный предмет каталога, сначала в руках, затем надевание; тяга/управление/коллизии; индикатор надетого без занятия quick-slot; кнопка снятия вне основных зон касания.
9. Сборка APK, тесты и PR в main. Не публиковать незавершённое лобби как готовую функцию.

Карта, исходные модели, каталог, коллизии, эффекты и функции FPV сохраняются. Тестов на телефоне у агента нет.
