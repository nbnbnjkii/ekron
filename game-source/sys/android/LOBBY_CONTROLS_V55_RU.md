# v0.55: исправление управления лобби и редактора

- Удалены нарисованные в пикселях джойстик/кнопки лобби и отдельный обработчик их пальцев. Теперь это те же StickView, LookView и HudButton, что используются игроком: мёртвая зона и нормализация стика, правосторонний обзор с чувствительностью .004, независимые пальцы, прыжок по нажатию и переключение приседания. Ускорение гравитации/прыжка согласованы с игроком (18/6.5).
- Лобби копирует позиции/размеры трёх основных контролов из игрового HUD и профиля игрока. Правка профиля сразу применяется и в лобби. Оружие/строительство по-прежнему недоступны.
- LookView получил необязательный обработчик тапа: неподвижное касание любой части монитора активирует надпись; левый свайп вне стика не превращается в обзор. В обычной игре порог начала обзора не изменён.
- Редактор: настоящие Android-кнопки в двух рядах по 56+ dp, 16sp текст, «Уменьшить», «Увеличить», «Сброс раскладки», «Сохранить и выйти». Больше нет строки мелкого текста с невидимым делением экрана на четверти.
- Редактируемая область вписана между верхним выбором элемента и нижней панелью. Кнопки из нижнего края игрового HUD больше не спрятаны под панелью редактора. Вместо квадратных заглушек рисуются сами игровые контролы.
- Для мелких/перекрытых элементов есть крупный список выбора сверху, а не только попадание по превью. Изменение размеров без выбранного элемента недоступно. Перетаскивание учитывает масштаб превью; элементы ограничиваются размером игрового экрана. Сохранение выполняется явно кнопкой выхода.
- Исправлена исходная точка превью при уже увеличенном контроле. Лобби начинает ближе к главному монитору, у надписей появились явные фоновые зоны; заголовок больше не включает первую команду по ошибке.

Проверки: APK/JVM/native/GLSL CI; добавлены device-side LobbyControlsTest (проверка реальных классов контролов, четырёх отдельных больших действий и сохранения при выходе). Без устройства эти instrumentation-тесты не запущены. Не утверждать, что удобство/тач проверены на телефоне. Реализация лобби по-прежнему Canvas-проекция, не перенос в игровой GLES-мир.
