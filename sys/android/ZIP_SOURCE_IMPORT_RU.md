# Обновление исходников из game-source.zip

Источник: https://github.com/nbnbnjkii/ekron/blob/806a5f6cf94478cb5430a13c574248f5108c4587/game-source.zip
Git blob архива: `1c8d2215d638de3fb57f57234e64e341a629020f`.

В архиве 197 файлов, моделей GLB/GLTF/OBJ/FBX/BLEND нет. Архив распакован и объединён с текущими папками `game-source/`, `sys/android`, `tests/native`, `tools`. Файлы, отсутствующие в архиве, не удалялись. Все существующие 14 файлов моделей в репозитории проверены по Git blob SHA-1: содержимое не менялось.

По явному выбору пользователя сохранена военная карта v0.50: `military_city.glb`, коллизии, эффекты огня/дыма/пепла, старт (24,104), поддержка цветов вершин, оптимизация и этапы загрузки. ZIP основан на v0.47; его старые ссылки на abandoned_city_street_for_games.glb и откат сборки на v0.47 не применены. Сохранён расширенный CI с проверками новой карты/шейдеров/частиц вместо сокращённой архивной версии workflow. Другие отсутствующие в ZIP файлы также оставлены на месте.

Применены новые изменения архива:
- 16 дополнительных предметов каталога (ID 13..28), их геометрия, размеры, массы и сохранение/загрузка;
- расширенные диапазоны команд размещения и проверок допустимых типов;
- разделение категорий, отображение новых предметов и JVM-тесты;
- настройки `.zed` в `game-source/`.

Совмещение выполнено трёхсторонним слиянием с исходной базой 4a125d8867ac54ce7d52b5cc03dd64e55de487b1: новые изменения ZIP добавлены поверх интеграции карты, а не слепой заменой несовместимыми старыми файлами. Дополнительно исправлено только форматирование нескольких последовательных if/for из ZIP для сборки с -Werror. Регрессионный тест `archive_catalog_test.cpp` проверяет геометрию и сохранение всех новых типов. Проверка недопустимого ID в sandbox_world_test обновлена с 13 на kObjectTypeCount.
